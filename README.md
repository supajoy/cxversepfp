# linkedin frame

internal tool — drop a photo inside the frame and export a 1000×1000 png for linkedin.

## use

open `index.html` in a browser, or visit the deployed vercel url. choose an image, drag to reposition, scroll or use the slider to zoom, then download.

## files

- `index.html` — single-file app (vanilla html/css/js)
- `frame.png` — overlay (1796×1796, drawn at 1000×1000 on export)
